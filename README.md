
# Function Generator

A custom-designed function generator developed from scratch, encompassing circuit design, simulation, PCB development, and hardware verification.

## Project Overview

The objective of this project is to design and implement a function generator capable of producing multiple waveform types with adjustable frequency and amplitude.

The project explores analog circuit design, signal generation, amplification, power regulation, and PCB development.
